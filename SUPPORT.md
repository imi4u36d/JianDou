# Support

JianDou is community-supported. Please choose the channel that matches the kind of help you need so maintainers can respond efficiently.

## Usage Questions

For setup, configuration, model provider, or deployment questions:

- Check [README.md](README.md), [docs/configuration.md](docs/configuration.md), and [docs/database-design.md](docs/database-design.md) first.
- Search existing GitHub issues before opening a new one.
- Include your operating system, Python version, Node version, deployment method, database URL scheme, and JianDou commit or version.

You can also use the project community channel listed in [README.md](README.md) for informal discussion.

## Bugs

Open a GitHub bug report when you can provide reproducible steps. Good reports include:

- The smallest steps that reproduce the problem.
- Relevant logs, API responses, screenshots, or stack traces.
- Whether the problem happens locally, in Docker, or behind a reverse proxy.
- Confirmation that API keys, tokens, cookies, and database contents have been removed from shared logs.

## Feature Requests

Open a GitHub feature request for product, API, model-provider, or workflow improvements. Describe the user problem, proposed behavior, and any alternatives you considered.

## Security Issues

Do not open a public issue for vulnerabilities or secret exposure. Follow [SECURITY.md](SECURITY.md) for private disclosure guidance.

## Maintainer Expectations

This project is alpha software. Maintainers prioritize reproducible bugs, security reports, data-loss risks, and changes that improve setup reliability for new contributors.
